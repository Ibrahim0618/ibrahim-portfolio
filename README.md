# Muhamed Ibrahim — Purple DevOps Portfolio

A responsive, black-and-neon-purple portfolio website built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `ibrahim-purple-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
- Replace the white photo placeholders in `index.html` with your own images.
- Replace `YOUR_INSTAGRAM_USERNAME` with your Instagram username in both social link locations.
- Update education dates and results with your actual information.
- Check that the internship and certification descriptions match your experience and certificate titles.
- If any project repository URL changes, update the corresponding `href` in the Projects section.
- The skill logos load from the Devicon CDN and the font loads from Google Fonts, so those assets require an internet connection.

## Publish on GitHub Pages
1. Create a repository named `portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the provided URL.

- Replace these two local images if you want to change photos later.
